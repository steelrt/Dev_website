📂 STEP 1: CREATE FOLDER STRUCTURE

TROUBLESHOOTING:
================

Issue: Images not showing
  Cause: Incorrect path or missing images
  Fix 1: Check image filenames match exactly
  Fix 2: Verify folder structure is correct
  Fix 3: Check file extensions (.jpg vs .JPG)

Issue: Page looks wrong on mobile
  Cause: Browser zoom or responsive issue
  Fix 1: Try different browser
  Fix 2: Check zoom level (should be 100%)
  Fix 3: Resize browser window to test

Issue: Can't open HTML file
  Cause: No default browser set
  Fix 1: Right-click → Open with → Choose browser
  Fix 2: Drag HTML file into browser window
  Fix 3: Copy path, paste in browser address bar

Issue: FAQ not expanding
  Cause: JavaScript disabled
  Fix: Enable JavaScript in browser settings

Issue: Phone links not working
  Cause: No phone app installed (on desktop)
  Fix: Normal on desktop, works on mobile phones
