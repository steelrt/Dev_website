HOW TO CHANGE IMAGES:
====================

1. Image Replacement:
   - Save new image in assets/images/
   - Keep same filename OR
   - Update filename in HTML

2. Image Format:
   - Use JPG for photos
   - Use WebP for better compression
   - Use PNG for logos/graphics

3. Image Optimization:
   - Compress before uploading
   - Use TinyPNG.com for compression
   - Keep file size < 500KB each

4. Adding New Images:
   - Place in assets/images/
   - Reference in HTML: src="assets/images/filename.jpg"
