🆘 QUICK HELP:

Problem: Images not showing?

       Verify image filenames match HTML

Problem: Website looks broken?
  Fix: Try different browser
       Check zoom level (should be 100%)
       Clear browser cache

Problem: Can't upload files?
  Fix: Check file size < 2GB each
       Verify FTP credentials
       Try different FTP client

Problem: Domain not working?
  Fix: Wait 24-48 hours for DNS
       Check nameservers in registrar
       Verify domain points to hosting
